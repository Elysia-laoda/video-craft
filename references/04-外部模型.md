# 04 外部模型：代码与生图

## 1 中转站

- Base URL：`https://la-api.vxvxvx.top/v1`（OpenAI 兼容）
- Key：`~/.dsh/.credentials.yaml` 的 `refs.VX_API_KEY`（**不要打印**）
- 可用模型（2026-11 实测）：

| 用途 | 模型 | 备注 |
|---|---|---|
| 写 TSX / 前端 | `claude-opus-5-5-max`、`claude-sonnet-5-5-max` | 质量最好，长输出易被代理掐断 |
| 写 TSX（稳定吐长文） | `gpt-6-astra-max`、`gpt-6.1-sol-max` | **流式**可稳定吐 20KB 级 |
| 生图 | `gpt-image-2.5-pro` | 概念图、产品渲染 |
| 生图（备选） | 百炼 `wan2.2-t2i-flash` | 用 `ALI_API_KEY`，异步任务 |
| 不可用 | `gemini-4-carbon-max` | 该端点返回 HTML |

## 2 让它写组件：提示词模板

```text
你在 Remotion 4 + React 19 + TypeScript(strict) 项目里工作。
只输出一个 .tsx 文件，不要解释、不要 markdown 围栏。
- 组件：export const Name: React.FC<{ at: number }> = ({ at }) => {…}，并 export default
- 根元素 <AbsoluteFill>，自带深色底
- y<300 是字幕带，禁止放主要内容；x 不越 80–1840
- 禁止 Math.random / Date.now / CSS animation；随机用 rnd(seed)
- 只用 react + remotion，不加依赖
- 画风：手绘版画感 SVG（path、线宽 1–3、冷灰描边、boil 抖动），不要照片/3D/塑料渐变
- 画面里的物体必须一直在动（人、车、灯、蒸汽、雨、镜头推进）
文件名：src/scenes/art/Name.tsx；组件名 Name。
```

**场景描述要具体到物件**：写"骑楼、招牌、灯笼、骑车人、追车的小孩"，不要写"台南的怀旧氛围"。

## 3 三种调用方式（按稳定性排序）

1. **本机 Claude Code CLI**（最稳）：
   ```powershell
   $env:ANTHROPIC_BASE_URL="https://la-api.vxvxvx.top"
   $env:ANTHROPIC_AUTH_TOKEN=$key
   echo "<prompt>" | claude -p --model claude-opus-5-5-max --max-turns 1 --output-format text
   ```
   Node 里用 `spawn(claude.cmd, [...], { shell: true })` + **prompt 走 stdin**（走 argv 会被 shell 转义弄坏）。
2. **直接 fetch 流式**（gpt 系最稳）：`stream:true`，逐块拼 `choices[0].delta.content`，超时 300s，失败重试 2 轮。
3. **非流式**：小输出（<3KB）可用；长输出经常 socket closed。

## 4 产出必须人工过一遍

| 问题 | 修法 |
|---|---|
| 把 `at`（绝对秒）当帧用：`const t = frame - at` | 改成 `const t = frame`，`at` 只用于取颜色 |
| 组件收了不存在的 props | 统一签名 `{ at: number }` 或空 |
| 内容压到 y<300 | 整体下移，或缩短行数 |
| 用了三方的库 | 删掉，用 SVG 重画 |
| 出现照片/emoji | 换成手绘 |

## 5 生图

```js
// gpt-image-2.5-pro（OpenAI 兼容）
POST /v1/images/generations { model:"gpt-image-2.5-pro", prompt, n:1, size:"1536x864" }
// 返回 data[0].url 或 b64_json

// 百炼 wan2.2-t2i-flash（异步）
POST https://dashscope.aliyuncs.com/api/v1/services/aigc/text2image/image-synthesis
  header X-DashScope-Async: enable
  body { model:"wan2.2-t2i-flash", input:{prompt}, parameters:{size:"1280*720", n:1} }
→ 轮询 /api/v1/tasks/{task_id}
```

- 产品类提示词：`photorealistic product photo, dark studio, single module on matte black plinth, rim light, shallow depth of field, no text, no logos`
- 生成图**要做角标**：概念图/示意图必须标出来，不能冒充实物。
- 用前用 vlkit 看一眼：有没有乱码文字、畸形结构。
