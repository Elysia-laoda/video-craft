# 08 音效与素材：取法、挑选、许可证

> 从旧技能 `code-rendered-video/references/sfx-sourcing.md` 并入（2026-11 迁移）。

## 1 Pixabay（首选，质量好）

**关键认知：Cloudflare 只挡搜索页，不挡 CDN。**

1. 用 CDP 驱动一个**专用 profile** 的 Chrome：
   `chrome.exe --remote-debugging-port=9222 --user-data-dir=<专用目录> --remote-allow-origins=*`
   （websocket-client 连接要 `suppress_origin=True`）
2. **人在窗口里过一次 Cloudflare 验证并登录**——脚本过不去，这一步必须是人。
3. `Page.navigate` 到 `https://pixabay.com/zh/sound-effects/search/<关键词>/`
4. 等 5–6 秒，从渲染后的 HTML 里正则抠 `cdn\.pixabay\.com/audio/*\.mp3`（每页约 20 条）。
5. **换回普通 urllib 直接下载**（带 UA + Referer）——这一层没有 Cloudflare，实测一次全成。

**许可证**：Pixabay Content License —— 免费商用、无需署名，但**不得把素材文件本身原样再分发**（放进作品可以，当素材库转卖不行）。原始文件不要提交进公开仓库。

## 2 Wikimedia Commons（备选，免密钥、许可证字段全）

```
https://commons.wikimedia.org/w/api.php?action=query&format=json
  &generator=search&gsrsearch=filetype:audio <关键词>&gsrnamespace=6
  &prop=imageinfo&iiprop=url|extmetadata|size
```

- **必须带 User-Agent**（Wikimedia 的硬要求，否则被拒）。
- 坑一：自由文本检索很噪（搜"风扇"会返回里根演讲），要换关键词反复试。
- 坑二：**分类名不是想当然的**（`Category:Sounds of breaking glass` 之类多为空），别依赖分类。
- 注意：DSH 的 `web_fetch` 对几十字节的 API JSON 会直接拒——改用 Python urllib。

## 3 挑选：按测得的特征，不靠感觉

| 特征 | 用途 |
|---|---|
| 时长 / RMS / 峰值 | 够不够用、响度合适否 |
| 频谱重心 | 玻璃要**亮**（高）、呼啸要**沉**（低） |
| <200Hz 能量占比 | 底噪与撞击要**高**（有低频） |
| 包络一阶差分峰值 ÷ 包络均值 | 撕裂、点击类要**高**（瞬态尖锐） |

实测挑选样例（6 类各 3 个候选里选 1）：打字选最长最响的（20.04s / −28.6dB）；底噪选低频占比最高的（23.0%）；撞击选有低频冲击又不拖尾的（1.07s / 18.6%）；玻璃选频谱最亮的（重心 6896Hz）；撕纸选瞬态最尖锐的（0.9）；呼啸选最沉的（重心 666Hz / 低频 43.2%）。

## 4 没素材就自己合成

短促的点击、翻页、撞击、雨声，用 ffmpeg 造比找更可控：

```powershell
# 撞击：短噪声 + 快速衰减
ffmpeg -f lavfi -i "anoisesrc=d=0.25:c=brown" -af "afade=t=out:st=0.02:d=0.22,highpass=f=60" impact.wav
# 翻页：带通噪声 + 两段信封
ffmpeg -f lavfi -i "anoisesrc=d=0.18:c=pink" -af "bandpass=f=2400:w=1800,afade=t=in:d=0.01,afade=t=out:st=0.06:d=0.12" paper.wav
# 低频轰鸣（riser 的底）：正弦扫频
ffmpeg -f lavfi -i "sine=f=60:d=1.2" -af "vibrato=f=3:d=0.6,afade=t=in:d=0.4" boom.wav
```

自合成素材**没有第三方权利**，可以放心分发；缺点是听感偏"电子"，只在短促动作上用它。

## 5 许可证分级

| 级别 | 处理 |
|---|---|
| CC0 / Public domain | 直接用，无需署名 |
| CC BY | 可用，**必须署名**（写进清单） |
| CC BY-SA | 公开视频上**有传染性风险**，避免；除非确认整片可用同一许可 |
| 仅个人/教育用途（BBC Sound Effects、ZapSplat 等） | **一律排除** |
| 需购买许可、带水印或试听语音 | 排除；下载后要验证不是静音、不含人声水印 |

## 6 处理链

- 转 **44.1 kHz / 单声道 / 16-bit PCM WAV**。
- 键盘、撕裂这类**尖峰型**录音，峰值归一后响度仍然很低，要加**压缩**（实测两级 `acompressor` + `loudnorm=I=-16` 才够）。
- 峰值归一 −3 dBFS（或 `loudnorm TP=-2`）。

## 7 纪律

- **不注册账号、不申请 key、不绕登录墙**（除非用户明确提供账号并要求使用）。
- 每个文件下载后**验证**：ffprobe 读规格、确认不是静音、不是水印试听版。
- 交付时给**许可证清单**：文件名 / 原始标题 / 作者 / 来源页 / 许可证类型 / 是否需署名 / 处理变换。
- 被拒的候选也要记下理由（例如某撞击素材是 CC BY-SA，改用自合成）。
