# 05 验收：只认数字与抽帧

## 1 六个数字

```powershell
python templates/验收脚本/verify_film.py <成片.mp4>
```

| 项 | 判据 | 说明 |
|---|---|---|
| 帧数 | = 时长 × fps（±1） | `ffprobe -count_frames` |
| 时长 | 与音乐一致，结尾不黑 | 黑场 MAD = 0.000，会吃掉冻结配额 |
| 音轨 | AAC 48k 立体声，满铺 | 缺失立刻发现 |
| 动效密度 P10 | ≥ 0.30 | 每 1/6 秒窗 MAD 的第 10 百分位 |
| 峰值 ÷ 空档 | ≥ 5 | 空档 = 去掉最大峰值附近后的中位 |
| 冻结窗口 | < 20% 最好；30–40% 要在报告里解释 | 留白段落是有意的就写清楚 |

## 2 动效密度怎么读

- **中位 0.35–0.8** 是舒服区；< 0.2 就是"幻灯片感"。
- **P10 低而中位正常** = 有一段一段地"停住"。
- 拉开逐 10 秒表，看**每段的最小值**：最小值 < 0.1 的那几秒就是死画面。
- 定位到死画面后，**加真实运动**（人/物/光/镜头），不要加全局亮度抖动。

## 3 字幕同步抽查

抽 3 个时间点（开头、中有词处、结尾）：

```powershell
ffmpeg -ss 5 -i film.mp4 -frames:v 1 -y check_5.png
```

用 vlkit 问"①逐字读出画面上方歌词；②画面主体是什么"，与 `lyrics.ts` 里该时刻的句子对照。

## 4 颜色/渐变抽查

```python
python templates/验收脚本/check_lyric_color.py
```

做法：裁字幕带区域 → 取饱和度高、亮度够的像素 → 求平均 RGB。
例：红起蓝收的片子，首帧应接近 (170,57,52)，末帧接近 (50,82,182)。

## 5 版面检查

- 用视觉模型只问**版面**：有没有重叠、越界、压字。
- **不要**让它转述文字（它会把数字、型号说错）。
- 真实的文字校验：从 DOM 读（`page.evaluate`）或对渲染前的数据做断言。

## 6 报告怎么写

```
| 项 | 结果 |
| 规格 | 8133 帧 / 271.147s / AAC 48k |
| 动效密度 | P10 0.195 / 中位 0.388 / 冻结 34% |
| 字幕 | 5s「…」/ 100s「…」/ 262s「…」 |
| 颜色 | 5s RGB(170,57,52) → 262s (50,82,182) |
| 已知不足 | 180–240s 为留白段落，近静止窗口集中于此 |
```

**不要**把没量过的项写成"通过"。没红过的检查不算检查。

## 7 长片加一项：逐镜抽检（空镜/糊镜）

```bash
python templates/验收脚本/blank_shots.py film.mp4 remotion/src/manifest.json
```

每镜取 15% / 50% / 85% 三帧，量亮度与对比；**亮度 < 9 或对比 < 6 就是空镜/糊镜**（片尾字幕卡可例外）。
单帧抽检会漏掉"每隔几镜一次的黑段"，这一项必须全片跑。

## 8 音频削波修复（不重渲）

```bash
ffmpeg -i film.mp4 -c:v copy -af "alimiter=limit=0.93:level=disabled,volume=-1.2dB" -c:a aac -b:a 256k fixed.mp4
```

视频流直接复制，几秒完成。修完再量一遍 `volumedetect`，峰值应 ≤ −1 dB。
