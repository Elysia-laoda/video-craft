## 1 最小工程

```

├── package.json      # remotion 4.0.484 + react 19 + @remotion/cli
├── tsconfig.json     # jsx: react-jsx, strict, noEmit
├── public/
│   ├── audio/bgm.mp3
│   ├── fonts/{kaiti,notoserif,heiti}.ttf
│   ├── photos/…
│   └── gpus/…

    ├── index.ts      # registerRoot(RemotionRoot)
    ├── Root.tsx      # <Composition> + 时间轴 + 字幕层 + 音频
    ├── theme.ts      # 色板/字体/缓动/rnd/tri/boil
    ├── lyrics.ts     # 字幕（或台词）时间轴

    └── scenes/       # 一段一个组件
```

```ts
// index.ts
import { registerRoot } from "remotion";
import { RemotionRoot } from "./Root";
registerRoot(RemotionRoot);

// Root.tsx 片段

```

## 2 确定性三件套

```ts
// theme.ts
export const rnd = (seed: number) => { /* mulberry32 */ };
export const tri = (x: number, period = 1) => { /* -1..1 三角波 */ };
export const boil = (f: number, seed = 1) => Math.round((rnd(Math.floor(f / 2) * 31 + seed) - 0.5) * 0.9);
```

- **禁止** `Math.random()`、`Date.now()`、`performance.now()`。
- 需要"随机"的布局（星点、灰尘、人潮）全部 `rnd(i * 53 + 7)`。
- 微妙的手绘抖动用 `boil(f, seed)`（两帧量化，像手绘动画的 line boil）。

## 3 常用组件（可直接抄）

| 组件 | 作用 | 关键实现 |
|---|---|---|
| `Camera` | 每段一层缓慢推拉/横移 | `scale(1→1.05) + translate + rotate(≤0.35°)`，**属于运镜，不是假动效** |
| `Kinetic` | 文字逐行遮罩上浮 | `overflow:hidden` + `translateY(110%→0)` + stagger |
| `Typed` | 打字机（公告、信件） | 按 `cps` 计算已显示字符，光标每 15 帧闪 |
| `Photo` | 照片 2.5D | 缩放 + 平移 + 灰度 + 双色调 + 半调网点 |
| `Chart` | 曲线逐帧描线 | `strokeDasharray` + 末端光点 |
| `Wafer` | 晶圆/die 网格 | 圆 + 网格 + 扫描线 + 旋转 |
| `Flowers` | 落花/纸屑 | 每片独立相位，落到地面堆积 |
| `Grain/Vignette` | 胶片感 | 静态噪点图 + 每帧平移抖动；径向暗角 |

## 4 布局安全带

```
y 0–80      片名小标 / 章节 slug
y 118–260   字幕带（歌词/台词）—— 任何场景文字不许进来
y 300–980   场景主区
y 980–1080  出处、署名、版权
```

字幕带上可以加 `radial-gradient(60% 100%, rgba(0,0,0,.62), transparent)` 暗底。

## 5 字体

- 本机可用：`STKAITI.TTF`（楷体，适合古诗/抒情）、`NotoSerifSC-VF.ttf`（宋）、`simhei.ttf`（黑）、`msyh.ttc`（雅黑）。
- **复制到 public/fonts 再用 `@font-face` 声明**，别依赖系统字体名——渲染机不一定有。
- 中文标题字距 0.1–0.2em 更好看；正文 0.04em。

## 6 性能

- 3000× 的 SVG 重绘会拖慢渲染：每帧元素控制在 300 个以内；网格用循环生成但别嵌套三层。
- `<Img>` 用 `staticFile`，原图别超过 2000px 宽（先 ffmpeg 压）。
- 长片（>5 分钟）分段渲染再拼接更稳：`--frames=0-2000` 三板然后 `ffmpeg -f concat`。

## 7 常见编译坑

| 现象 | 原因 | 解法 |
|---|---|---|
| `'g' has no corresponding closing tag` | 替换区块时丢了 `</g>` | 逐个标签核对 |
| `Type '{...}' is not assignable` | 生成的组件多了不存在的 props | 统一成 `{ at: number }` 或空 props |
| `Cannot find module './art/X'` | 生成脚本写到了别的目录 | 移动文件或改 import 路径 |
| 渲染中途崩 | 并发太高 / 内存 | `--concurrency=4`，关掉其它重活 |
