# 07 坑表（30 条实测）

## 音乐与时间轴

| 坑 | 症状 | 解法 |
|---|---|---|
| BPM 估错 | 末尾整体偏移 | 用自相关 + 相位扫描；宁可手工校准 |
| 用了 `ffmpeg astats` 的 BPM | 差 1–2 | 自己算 onset 包络 |
| 把首拍当 0 | 全片差半拍 | 扫相位取能量最齐的位置 |
| 音频被重采样两次 | 时长变 2 倍 | 用 `wave` 读 16-bit PCM，别中途 resample |

## Remotion / 渲染

| 坑 | 症状 | 解法 |
|---|---|---|
| `loop` + 音量回调 | 静音窗漏底噪 | 音频先拼成整段长文件 |
| 并发 8 长片 | 渲染中途崩（ChildProcess 报错） | `--concurrency=4` |
| 首帧下载 headless shell 失败 | 国内网络 | 指定 `--browser-executable` |
| 字体用了系统名 | 换机器全变宋体 | 字体复制进 `public/fonts` + `@font-face` |
| 字幕压场景文字 | 顶部两层字重叠 | 字幕带 y 118–260，主文字 y ≥ 300 |
| CSS transition | 渲染时不动 | 全部改成帧驱动 |

## 假动效（重点）

| 坑 | 症状 | 解法 |
|---|---|---|
| 加漂移光斑/亮度抖动刷 MAD | 数字好看，观众只觉得"脏" | 删掉；改成物体自身运动 |
| 全局 DC 亮度变化 | 暗场里被量化吃掉 | 必须空间性变化 |
| 正弦呼吸 | 极值处变化率归零，留死窗口 | 用三角波（斜率恒定） |
| 段落入场后静止 | 冻结窗口 60% | 加运镜 + 持续运动元素 |

## 外部模型

| 坑 | 症状 | 解法 |
|---|---|---|
| 长输出被代理掐断 | `socket closed` / `terminated` | 流式 + gpt 系；或本机 claude CLI |
| Claude CLI 用 argv 传 prompt | `no stdin data received` | prompt 走 stdin，`shell:true` |
| `claude.cmd` 直接 spawn | `EINVAL` | `shell:true` |
| 生成代码 `t = frame - at` | 动画整体错位 | 改成 `t = frame` |
| gemini-4-carbon-max | 返回 HTML | 换模型 |
| 概念图当实物 | 误导观众 | 角标"概念图" |

## 素材与许可

| 坑 | 症状 | 解法 |
|---|---|---|
| Pixabay 搜索页 403 | 直接 requests 拿不到 | 只让 CDP 浏览器过验证，下载走普通 urllib（CDN 不挡） |
| Commons 检索很噪 / 分类为空 | 搜"风扇"返回演讲 | 换关键词多次试，别依赖分类名；必须带 User-Agent |
| Commons 429 | 批量下载被限 | 每次请求间隔 3–4 秒 |
| CC BY-SA 混进商用片 | 传染性许可 | 优先 PD/CC0，其次 CC BY |
| web_fetch 拿不到 Commons API | 几十字节的 JSON 被直接拒 | 改用 Python urllib + UA |
| 忘了署名 | 侵权 | 片尾 + README 双写 |

## 流程

| 坑 | 症状 | 解法 |
|---|---|---|
| 先画画面再想结构 | 大量返工 | 音乐 → 剧本 → 节拍表 → 场景 |
| 用全片试参数 | 一次十几分钟 | 先渲 5–10 秒探针 |
| 改时间段只改一处 | 五处联动错位 | Sequence / 字幕表 / 组件 start / 剧本 / 节拍表 |
| 视觉模型转述文字 | 数字型号说错 | 文字从 DOM 或数据断言取 |

## 长片 / manifest（2026-11 实测，72 镜 300 s）

| 坑 | 症状 | 解法 |
|---|---|---|
| 改 `dur` 没重排 `from` | 每隔几个镜头出现一次纯黑空镜，MAD 掉到 0.04 | cursor 累加重排；断言 `from[i]==from[i-1]+dur[i-1]` 且总和 = 时长×fps |
| 场景把 `dur` 当秒又乘 fps | 动画在前 1/30 就跑完，剩下静止或黑屏 | 统一传帧数；或故意传 `dur × 1.3` 让动画跨满镜头 |
| 相机调试值留在 Root | 全片被放大 2.2 倍，晕 | 抽一帧对比；推镜系数 ≤ 0.04 |
| 改字符串替换静默失败 | 以为改好了，其实文件没变 | 改完 grep 一遍关键行；用正则而不是带具体数值的子串 |
| 只抽单帧就验收 | 抽帧正常、整片却有黑段 | 全片跑 `blank_shots.py`（每镜 15/50/85% 三点） |
| 旁白做成字幕条 | 和歌词抢位置、观感乱 | 做成画面内小字（左下角 + 细竖线），y ≥ 850 |
| 歌词加淡黑底 | 压住画面、观众嫌脏 | 去掉底衬，用三重暗字影保证亮背景可读 |
| 故事时间被歌词块绑架 | 出现倒叙、跳戏 | 叙事片按故事时间排镜头，歌词退为画外评论 |
| BGM 0.9 + 音效叠加 | 峰值 0.0 dB、爆音 | 已渲的片子用 `alimiter` + `-c:v copy` 秒修 |
| 音效轨按旧时长写 | 换片长后全部错位 | 事件表从 manifest 派生（`sfx_synth.py`） |
| 分发母版直接发 | 300 s 1080p 200–350 MB | CRF 26 + faststart → 约 47 MB |
| 打包忘脱敏 | 绝对路径、密钥、账号混进 zip | 打包前逐行扫 `projects`/`Users\\`/`key`/`token` |
