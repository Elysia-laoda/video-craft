# 11 声音设计与混音

## 1 三层结构

```
BGM  ——  整段音乐，音量 0.85–0.92，不做 loop
SFX  ——  逐镜事件表，峰值比 BGM 低 6–10 dB
人声 ——  旁白（若有）：合成后量实际时长再回排锚点；纯字幕方案则不占音轨
```

## 2 逐镜音效表（推荐做法）

不要"凭感觉铺 100 个音效"，而是**从 manifest 派生**：

| 场景类别 | 音色 | 落点 |
|---|---|---|
| 雪原 / 冰原 | 带通噪声 700–6000 Hz | 镜头起点，2–3 s 长 |
| 电波 / 仪表 | 1180+590 Hz 短脉冲 | 起点 + 每 20 帧一次 |
| 爆炸 / 撞击 | 90→34 Hz 下扫 + 低频噪声 | 起点，或动作帧 |
| 金属切片 | 2.6–12 kHz 噪声 + 快包络 | 每个切点 |
| 心跳 | 55/48 Hz 双 thump | 起点 + 每 1.6 s |
| 飞船掠过 | 300–4200 Hz 带通 + 指数衰减 | 起点 |
| 广播 | 220/110 Hz 调幅 | 起点，1.5–2 s |
| 门轴 / 关门 | 72→40 Hz 下扫 | 动作帧 |
| 按键 / 灯灭 | 1.6–9 kHz 极短 click | 动作帧 |

一支 72 镜的片子约 **92 个事件**（部分镜头补第二击）。生成脚本见 `templates/验收脚本/sfx_synth.py`。

## 3 合成而不是采样

- 代码合成的好处：**可以精确落在帧上**，不依赖素材的起音位置。
- 常用四件套：带通噪声（风/金属/水）、正弦下扫（撞击/关门）、指数包络（瞬态）、调幅（广播/心跳）。
- 采样素材（Pixabay / Commons）留给"合成不出来的东西"：真实脚步、雨、玻璃碎。取法与许可见 `08-音效与素材.md`。

## 4 混音与限幅

- 逐窗量电平：`ffmpeg -ss A -t B -i film.mp4 -af volumedetect -f null -`，看 `mean_volume` / `max_volume`。
- **峰值必须留头**：目标 ≤ −1 dB。BGM 0.9 + 音效叠加很容易顶到 0.0 dB（实测出现过两次）。
- 已经渲完的片子别重渲：`ffmpeg -i in.mp4 -c:v copy -af "alimiter=limit=0.93:level=disabled,volume=-1.2dB" -c:a aac -b:a 256k out.mp4` —— 视频流直接复制，几秒钟搞定。
- 静音窗检验：刻意静音处应 ≤ −80 dB；若只有 −25 dB 左右，多半是某层没压干净（BGM 用 `loop` + 音量回调就会这样）。

## 5 常见错

| 症状 | 原因 | 修法 |
|---|---|---|
| 全片峰值 0.0 dB、有爆音 | BGM + SFX 叠加 | 限幅或整体降 1.5 dB |
| 音效"浮"在音乐上 | SFX 峰值和 BGM 持平 | SFX 降 6–10 dB，或只在频段上错开 |
| 静音窗有底噪 | 音效用 `loop`、或采样尾巴长 | 拼成整段、裁尾 |
| 换片长后声音错位 | 事件表还按旧时长写 | 事件表从 manifest 派生 |
