# 12 交付与打包

## 1 转码分发

| 目标 | 命令 | 300 s 1080p 体积 |
|---|---|---|
| 母版 | `--crf=20`（Remotion 直接出） | 200–350 MB |
| 网页/分享 | `ffmpeg -c:v libx264 -crf 26 -preset slow -pix_fmt yuv420p -c:a aac -b:a 160k -movflags +faststart` | **~47 MB** |

线稿 + 暗场的动画压缩率极高，CRF 26 基本无损感；先抽两帧对比再定档。

## 2 源码包结构

```
project/
├── README.md            规格、运行、素材清单
├── docs/                剧本 / 分镜总表 / 音乐分析 / 验收
├── research/            剧情与歌词等素材
├── scripts/             注册表生成 / 抽帧巡检 / 音效 / 验收
└── remotion/            src + package.json + tsconfig
```

**不要塞进去**：`node_modules`、渲染中间帧、字体（版权不明）、BGM（第三方版权）、成片母版。

## 3 打包前的三条清理

1. **路径**：绝对路径换成相对路径；在家目录里的换成 `~`。
2. **凭据**：API key、中转地址、账号路径，逐行扫一遍再删。
3. **来源**：如果不想透露生成方式，删掉调用脚本与提示词文件，在 README 里写清署名口径。

扫一遍确认无残留：

```powershell
Select-String -Path (Get-ChildItem -Recurse -Include *.md,*.ts,*.tsx,*.py,*.mjs) -Pattern 'projects|Users\\|api_key|token'
```

## 4 完整性校验

打包后 `Get-FileHash`，拷到虚拟机/网盘/另一台机器后再算一次，两个哈希必须一致。跨机传输（vmrun / SMB / 网盘）都可能静默截断。
