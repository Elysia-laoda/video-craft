# 10 长片与多镜头（>40 镜 / >3 分钟）

短片（<60 s、<15 镜）靠"一段一个震撼画面"就能成立；**长片靠的是时间轴管理**。这一篇是 72 镜 / 300 s 那支片子的全部教训。

## 1 唯一事实源：manifest.json

镜头一多，时间就不再写在组件里，而是写在**一张表**里：

```json
{ "id": "17", "comp": "Guqin", "from": 1248, "dur": 260,
  "scene": "运河上，看不见的丝", "cam": "固定", "boost": 1.0, "nar": "运河上，看不见的丝" }
```

`Root.tsx` 只做一件事：读表、按 `from/dur` 排 `<Sequence>`，字幕/旁白/音效全部从同一张表派生。

**改了表就必须整体重排**——见 §3 的空镜惨案。

## 2 镜头分配

| 片长 | 镜头数 | 单镜时长 | 节奏 |
|---|---|---|---|
| 60 s | 8–15 | 4–7 s | 每镜一个信息点 |
| 180 s | 30–45 | 4–6 s | 每幕 10–15 镜 |
| 300 s | 60–80 | 3.5–5 s | 三分之一处换幕 |

一支 300 s 的片子做 72 镜 = 平均 4.17 s。少于 50 镜会显得拖，多于 90 镜观众跟不上。

## 3 空镜惨案：改 dur 必须重排 from

把 24 镜拆成 49 镜时，只改了每段的 `dur`、没重算 `from`，结果相邻镜头之间留下 **111–246 帧的空档**——观众看到的就是"每两个镜头一个空镜头"，MAD 掉到 0.04。

**正确做法：cursor 累加**

```js
let cursor = 0;
for (const block of blocks) {
  rows.push({ from: cursor, dur: a }); cursor += a;
  rows.push({ from: cursor, dur: b }); cursor += b;
}
// 断言：rows[i].from === rows[i-1].from + rows[i-1].dur，且最后一行 from+dur === 总帧数
```

还要断言总和等于 `时长 × fps`，不然片尾会黑或截断。

## 4 每镜都要能"自证有画面"

成片后跑一遍逐镜抽检（`templates/验收脚本/blank_shots.py`）：每镜在 15% / 50% / 85% 各抽一帧，量**平均亮度**与**标准差**，低于阈值就是空镜或糊镜。

判据：亮度 ≥ 9、对比 ≥ 6。片尾字幕卡可以例外。

## 5 定镜 vs 运镜

- 大幅推镜（>15%）在长片里会让人头晕，尤其暗场。**默认定镜**：push ≤ 0.04、位移 ≤ 10px、旋转 ≤ 0.06°。
- 需要"活"就靠**画面里的东西动**（雪、尘、光、人），不是靠镜头怼。
- 相机参数改动后，一定**抽一帧对比**——我们有一次调试值 `push={1.2}` 留在 Root 里，替换字符串又静默失败，连续几版都在放大 220%，验收指标却没报错。

## 6 故事顺序 vs 歌词顺序

歌词驱动的片子有两种排法：

| 排法 | 适用 | 代价 |
|---|---|---|
| 镜头跟歌词块 | MV、情绪片 | 容易倒叙、跳戏 |
| 镜头跟故事时间 | 叙事片、科普、人物志 | 歌词退为画外评论 |

72 镜版选的是**故事时间顺序**：红岸 → 三体世界 → 面壁 → 水滴 → 执剑人 → 二维化 → 归零 → 蓝星。歌词仍在，但不再逐句对位。

## 7 旁白分层

- **不要做成字幕条**：字幕条一定和歌词抢位置。
- 做成"画面里的字"：左下角小字块 + 一条细竖线，字号比歌词小一半，逐字显影。
- 位置固定在 y ≥ 850（歌词带在 y 118–260），两者永不相交。
- 一镜一句、与画面内容对应；宁可短（≤ 18 字），不要念说明书。

## 8 抽帧巡检的节奏

| 阶段 | 做法 |
|---|---|
| 每画完 6–8 镜 | 抽中间帧拼 3×2 联系表，看整体色调与构图 |
| 换幕前 | 抽该幕首尾帧 |
| 全片前 | 0.35 比例渲染一遍草稿（几分钟），量 P10 与逐镜亮度 |
| 交付前 | 全片渲染 + 六数 + 逐镜抽检 |

草稿渲染（`--scale=0.35 --crf=28`）比全片快 5–8 倍，专门用来抓"空镜/黑镜/切错"。

## 9 一次成片的时间预算（24 镜 300 s 实测）

| 环节 | 耗时 |
|---|---|
| 单场生成（含重试） | 70–120 s |
| 单帧渲染 | 8–12 s |
| 全片渲染（9000 帧 / 1080p / c=8） | 30–40 min |
| 六数 + 逐镜抽检 | 5 min |
