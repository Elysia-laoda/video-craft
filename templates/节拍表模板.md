# 节拍表模板

帧号 = 秒 × fps。改任何时间段，**五处同改**：Sequence / 字幕表 / 组件 start / 剧本 / 本表。

| 段 | 时间 | 帧 | 拍号 | 画面 | 运镜 | 视线 | 字幕 | 旁白/编号 | SFX | 转场 |
|---|---|---|---|---|---|---|---|---|---|---|
| 序 | 0–3 | 0–90 | — | 黑场，一个红点从针尖长起 | 静止 | 焦点=点 | — | — | 极轻低频 | 硬切 |
| 一 | 3–12 | 90–360 | b4–b12 | 公告逐字打出 | 缓慢推近 1.02× | 焦点=公告首行 | … | — | 打字声 | 硬切 2 帧 |
| 二 | 12–24 | 360–720 | b12–b28 | | | | | N07 | | 叠化 6f |
| 尾声 | 24–30 | 720–900 | b28–b36 | | | | | | | 淡出 12f |

## 每一列怎么填

| 列 | 填什么 | 例 |
|---|---|---|
| 帧 | 秒 × fps，算出来的整数 | 90–360 |
| 拍号 | 用 `beat(n)` 的序号，便于卡点 | b4–b12 |
| 运镜 | 推/拉/横移/环绕/静止 + 幅度 | 推近 1.00→1.06 |
| 视线 | 观众先看哪、再看哪 | 先看标题，再落到手 |
| 旁白/编号 | 有旁白时填编号，音频表按编号对 | N07 |
| SFX | 音效名 + 落点（帧） | 打字 90/120/160 |
| 转场 | 硬切 / 叠化 / 黑场 + 帧数 | 硬切 2 帧 |

## 联动清单（漏一处就错位）

1. `Root.tsx` 的 `<Sequence from durationInFrames>`
2. `lyrics.ts`（或台词表）的 `t0/t1`
3. 组件内部 `start` 帧
4. 剧本的分段表
5. 本表
